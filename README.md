# 🎯 SmartBoardTools (智慧白板助手)
**一个让教室电子白板变得真正智慧的工具！**
**专为教室场景设计，集课程表、倒计时、AI问答于一体，运行在Windows电子白板上。由一名高中生，在仅有平板和云服务器的“极限”环境下开发完成。**

## ✨ 特性功能
- 🔔 **倒数日**: 可设为月考倒计时、高考倒计时等。
- 📅 **智能课程表**: 在屏幕顶端清晰展示当日课程，支持在修改课程表窗口编辑。
- ⏰ **上课倒计时**: 在课程表右边实时显示距离下一节课的时间。
- 🤖 **内置AI助手**: 一键唤出AI问答窗口（基于讯飞星火大模型），辅助课堂互动。
- 🎨 **极简交互**: 所有功能为触摸大屏优化，老师易上手，零学习成本。
-  📤 **配置轻松迁移**: 所有数据存于本地JSON文件，U盘拷贝即可分享给其他班级。

## 🛠 技术栈
这个项目展示了如何用轻量化的技术解决实际问题

| 部分 | 技术选型 | 说明 |
|--|--|--|
| **前端界面** | `HTML5` \| `CSS3` \| `原生JavaScript` \| `LayUI` | 纯原生开发，零依赖重型框架，保障在白板电脑上的流畅运行 |
| **桌面端** | [`Electron`](https://www.electronjs.org/) | 实现跨平台打包，完美适配Windows环境下的电子白板 |

## 📦 安装与运行
### 前提条件
- **操作系统**: Windows 10 / 11 64位 (已在常见电子白板系统上测试)
- **运行环境**: 无需额外依赖，已打包成可执行文件。
### 快速开始
1. 前往 [Release页面](https://github.com/FeedWhisper5148/SmartBoardTools_OpenSourced/releases) 下载最新的 `SmartBoardTools`。
2. 运行安装程序，将其安装到白板电脑上。
3. 启动 `SmartBoardTools`，尽情享用！
### 从源码构建
如果你想自行开发或打包：
1. **首先填写相关的apiKey信息，否则每日一词和AI不可用**
2. 执行以下代码：
```bash
git clone git@github.com:FeedWhisper5148/SmartBoardTools_OpenSourced.git # 克隆该项目到本地
cd SmartBoardTools_OpenSourced # 进入项目目录
npm install # 安装所需依赖
npm run start # 运行项目
npm run build # 构建安装包
```
## ❗️ 注意事项
1. 为避免干扰正常教学，上课时间不会显示课程表和每日一词窗口，如需预览效果，请修改时间表并**重启软件**
2. 修改时间表暂未实现热更新的功能，**修改后需重启软件才能生效**
3. 所提供的安装包自带apiKey等信息**已过期**，如需使用AI相关功能请自行修改并打包
